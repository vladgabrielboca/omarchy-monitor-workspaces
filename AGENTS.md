# AGENTS.md

Omarchy shell plugin giving each monitor its own workspaces 1–9,0 plus a focus badge.

## Layout
- `manifest.json` — plugin manifest (id `vladgabrielboca.monitor-workspaces`, kind `bar-widget`, entry `BarWidget.qml`).
- `BarWidget.qml` — bar widget (workspaces list and monitor badge). `HighlightPanel.qml` — badge highlight-colour menu.
- `Model.js` — pure helpers shared with tests (block lookup, labels, highlight parsing). Mirrors the Lua logic.
- `hypr/monitor-workspaces.lua` — Hyprland Lua keys and workspace engine; loaded from `~/.config/hypr/hyprland.lua`.
- `setup`, `teardown` — install/remove the Hyprland hook and bar layout (both `--yes` for non-interactive).
- `tests/*.sh` — bash test scripts. `i18n/en.json` — translated strings. README, LICENSE, screenshots.

## Commands
- Build: none; it is plain QML/JS/Lua/bash loaded by Omarchy.
- Test: `tests/model-test.sh` (needs node), `tests/lua-test.sh` (needs lua), `tests/setup-test.sh` (needs jq).
- Lint: none configured.
- Run/install: `./setup --yes`; disable: `./teardown --yes`; live reload: `hyprctl reload && omarchy restart shell`.

## Conventions
- QML: Qt 6 / Quickshell, 2-space indent, camelCase ids and properties, `qs.*` imports, comments above blocks.
- `Model.js` is QML library JS (`.pragma library`): ES5 style, `var`, no semicolons, pure functions only so node can load it.
- Lua: snake_case, 2-space indent, handles both Omarchy's built-in `o.workspaces` and its own fallback engine.
- Bash: `set -euo pipefail`; scripts take `ROOT` from `BASH_SOURCE`; tests sandbox with `mktemp -d` and XDG overrides, skip when node/lua is missing.
- User-facing text goes through `i18n/en.json` keys (prefixes `badge.`, `highlight.`).

## Do not touch
- `preview.png` and `screenshots/` — README media; regenerate only if asked.
- `*.bak.<timestamp>` files and the `>>> vladgabrielboca.monitor-workspaces >>>` block in the user's Hyprland config are generated by `setup`.
